## 🌟 Highlights

- 🖼️ **55 file-type icons** rasterized at 16 / 32 / 48 px (`@1x`, `@2x`, `@3x`) so Sublime picks the right size for your display scale
- 🔗 **64 `.tmPreferences` bindings** mapping file patterns (`*.ts`, `Dockerfile`, `package.json`, …) to 41 distinct icons
- 🎨 **Same source as the VS Code pack** - generated by `scripts/build-sublime.mjs` in [chalii-icons](https://github.com/chaliidesigns/chalii-icons) from the shared `manifest.mjs`
- 🏷️ **Tagged releases** - every version is tagged (`vX.Y.Z`) by the monorepo's `sync-sublime-repo.sh` so Package Control can fetch it

## ✨ Features

- PNG icons rendered from the Chalii SVG set with a single dark fill (`fg.default`)
- One `.tmPreferences` per icon binding a `file_patterns` list to `file_type_<name>`
- Works on macOS, Linux and Windows
- Pairs with the [Chalii Themes](https://github.com/chaliidesigns/chalii-sublime) colour schemes for Sublime Text

## 🚀 Quick Start

### From a tagged release

1. Download the latest tag of this repository as a zip (or clone it).
2. Rename the folder to `Chalii Icons` and zip its **contents** as `Chalii Icons.sublime-package`:

   ```bash
   cd "Chalii Icons" && zip -rq "../Chalii Icons.sublime-package" .
   ```

3. Drop the `.sublime-package` into Sublime's `Installed Packages/` directory and restart Sublime:
   - macOS: `~/Library/Application Support/Sublime Text/Installed Packages/`
   - Linux: `~/.config/sublime-text/Installed Packages/`
   - Windows: `%APPDATA%\Sublime Text\Installed Packages\`

### From the monorepo

```bash
# in chaliidesigns/chalii-icons
npm run build:sublime   # regenerates packages/sublime/Chalii Icons/ and chalii-icons.sublime-package
```

Then copy `packages/sublime/chalii-icons.sublime-package` into `Installed Packages/`.

## 🔧 How It Is Built

Everything here is emitted by [`scripts/build-sublime.mjs`](https://github.com/chaliidesigns/chalii-icons/blob/main/scripts/build-sublime.mjs):

1. Reads the shared icon manifest and rasterizes each SVG with `@resvg/resvg-js` at 1×/2×/3×.
2. Writes a `.tmPreferences` plist per icon with the file patterns from the manifest.
3. Zips the package if `zip` is on `PATH`.

Releases are mirrored into this repo and tagged by [`scripts/sync-sublime-repo.sh`](https://github.com/chaliidesigns/chalii-icons/blob/main/scripts/sync-sublime-repo.sh). **Do not edit files here directly** - open issues and PRs against [chalii-icons](https://github.com/chaliidesigns/chalii-icons/issues).

## ⚠️ Limitations

- Bindings are pattern-driven. Icons whose manifest entry has no file patterns / language IDs in the build's scope table are rasterized but **not** bound - not every one of the 55 icons is reachable yet.
- Single dark-fill rasterization. Sublime can't auto-swap icon colours per colour scheme without a separate package per palette.
